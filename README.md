# کارآگاه نورک — راز فواره خاموش (Detective Noorak)

یک بازی ماجراجویی معمایی دوبعدی (Point & Click) برای کودکان ۶ تا ۹ سال در جهان «سرزمین روشن».

## معرفی کوتاه
در میدان روشن، فواره کاشی‌کاری‌شده از کار افتاده است. کودک همراه با **نورک** (چراغک کوچک و دوست‌داشتنی با ذره‌بین) و **رها** وارد میدان می‌شود، سرنخ‌ها را کشف می‌کند، آن‌ها را در **دفترچه کارآگاهی** ثبت می‌نماید، فرضیه می‌سازد، شاهد می‌آورد و با باز کردن شیر آب، شادی و سرسبزی را به میدان برمی‌گرداند.

## تکنولوژی‌های استفاده‌شده
- **TypeScript** + **React** (رابط کاربری راست‌به‌چپ فارسی و واکنش‌گرا)
- **Phaser (v4.2.1 Canvas)** برای صحنه تعاملی دوبعدی میدان روشن
- **Vite** برای توسعه و Build سریع
- **Tailwind CSS** + فونت فارسی **Vazirmatn** (نصب‌شده به‌صورت محلی)
- **Web Audio API** برای افکت‌های صوتی ملایم بدون وابستگی به سرور

> **توضیح درباره نسخه Phaser:** پکیج رسمی `phaser` (نسخه `4.2.1`) با رندر `Phaser.CANVAS` استفاده شده است تا روی مرورگرهای موبایل، دسکتاپ و محیط‌های بدون شتاب‌دهنده سخت‌افزاری، پایدار، سریع و بدون افت فریم اجرا شود.

## روش نصب و اجرا
```bash
npm install
npm run dev
```
سپس در مرورگر آدرس زیر را باز کنید:
- `http://localhost:3000`

برای ساخت نسخه نهایی (Production Build):
```bash
npm run build
```

## روش مشاهده بازی روی گوشی موبایل
1. مطمئن شوید گوشی و کامپیوتر به یک شبکه Wi-Fi مشترک متصل هستند.
2. سرور توسعه با `--host=0.0.0.0` روی پورت `3000` اجرا می‌شود.
3. از آدرس شبکه محلی کامپیوتر خود (مثلاً `http://192.168.1.X:3000`) در مرورگر گوشی استفاده کنید.
4. برای بهترین تجربه، گوشی را در حالت **افقی (Landscape)** قرار دهید (بازی در حالت عمودی نیز کاملاً قابل اجرا است).

## ساختار پروژه
```text
src/
  assets/images/        تصویر پس‌زمینه صفحه عنوان
  cases/                تعریف داده‌محور پرونده‌ها و رجیستری سرزمین روشن
  characters/           شخصیت‌های SVG نورک، رها و ننه‌بهار
  components/           صفحه عنوان، HUD، دفترچه، فرضیه، شیر آب، راهنما و پایان
  core/                 منطق خالص و مستقل پرونده، ذخیره محلی و تست‌های واحد
  scenes/               صحنه دوبعدی Phaser میدان روشن و میزبان Canvas
  systems/              موتور صوتی Web Audio و رابط آینده اتصال گویندگی فارسی
```

## تثبیت فنی — Task 01

برای نصب تکرارپذیر از Node.js 22.12 یا جدیدتر (نسخه آزموده‌شده: 24.22.1) و npm استفاده کنید:

```bash
npm ci
npm run dev
```

نسخه‌های دقیق نصب در `package-lock.json` ثبت شده‌اند. فایل قدیمی `bun.lock` برای حفظ سوابق حذف نشده، اما مسیر نصب و بررسی این مأموریت npm است؛ Bun در این محیط آزموده نشده است.

بررسی نوع‌ها، تست منطق و تست واقعی مرورگر روی خروجی Production:

```bash
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm test` تمام فایل‌های `src/core/*.test.ts`، شامل شش آزمون اولیه، را با `node:test` از طریق `tsx` اجرا می‌کند. `npm run lint` قبلی همچنان بررسی TypeScript است. تست مرورگر، سرور preview مستقل روی `127.0.0.1:4173` راه‌اندازی و در پایان متوقف می‌کند؛ این پورت باید آزاد باشد. روی Linux دارای Chromium سیستم، اسکریپت از `/usr/bin/chromium` استفاده می‌کند و نیازی به دانلود مرورگر نیست. مسیر دیگر را می‌توان با `CHROMIUM_PATH` مشخص کرد. برای آزمون یک سرور از قبل اجراشده، `E2E_URL` را تنظیم کنید.

پیشرفت، انتخاب فرضیه و شاهد در `localStorage` با کلید `noorak_brightland_save_v1` ذخیره می‌شوند. راهنما و دفترچه انتخاب‌ها را حفظ می‌کنند؛ پس از Reload صفحه عنوان نمایش داده می‌شود و با ادامه، همان مرحله پرونده قابل بازی است. چرخش نیمه‌تمام شیر یک تعامل موقت است و پس از بسته‌شدن یا توقف، از صفر در مرحله `fix` شروع می‌شود. در حالت محدودبودن فضای ذخیره، بازی بدون ذخیره پایدار ادامه می‌یابد. داده‌های نامعتبر پالایش و مرحله‌های ناسازگار به مرحله‌ای قابل ادامه بازگردانده می‌شوند؛ schema ناشناخته به ذخیره پیش‌فرض بازمی‌گردد.
